# Surface Brief — Кабинет ОСИ (source/admin)

## THESIS
Рабочий стол сотрудника ОСИ: спокойный, деловой инструмент без декораций. Кабинет — не витрина, а пульт управления домом; пользователь открывает его много раз в день, и каждый лишний акцент — это шум. Красота здесь — в порядке: ровные сетки, тихая палитра, предсказуемые блоки.

## OWN-WORLD
Мир attio.com/help: светлый, монохромно-нейтральный, «бумажный». Белые карточки на серо-ледяном фоне (#f7f8f8), тонкие 1px-разделители вместо теней и цветных рамок, округлость умеренная (8–14px). Единственный живой цвет — фирменный зелёный #244c43 (из лендинга): он используется дозированно — логотип, primary-действия, акцент выбранного пункта меню. Всё остальное — графитовая шкала. Комп: system stack, плотность стандартная.

## STORY
Сотрудник открывает кабинет между звонками: слева — тихое белое меню-оглавление (как разделы help-центра), сверху — строка контекста, в центре — очередь дня. Он всегда видит, что требует его действия сейчас, и за один взгляд — где он находится. Ничего не мигает; интерфейс «отвечает», а не «развлекает».

## FIRST VIEWPORT
Светлый сайдбар с логотипом («гора» зелёным + МУНАР ТАУ), меню с выбранным пунктом — серая плашка с тёмным текстом; заголовок страницы и ровная таблица с тихими тегами статусов; одна primary-кнопка на экран.

## FORM
seed: none (unavailable). Геометрия: карточки 12–14px, контролы 8px, никаких цветных боковых рамок (side-tab под запретом) — зоны маркируются фоном/типографикой. Тени — лёгкие, с offset+blur (0 1px 2px / 0 1px 3px). Без kicker/eyebrow, без градиентного текста. Тёмная тема не вводим (кабинет дневной, светлый attio-референс).

## FINISH
Each element (spacing, type, dividers, tags) with crisp edges + clean rhythm.
