# ADR-022: AI-ассистент главной через DeepSeek

Дата: 25.10.2026. Статус: реализация согласованного AI-блока ADR-021.
Пользователь выбрал deepseek-flash / https://api.deepseek.com, 20 запросов
в сутки; технический администратор — без суточного ограничения.

## Контракт

Ассистент занимает всю ширину над виджетами, запускается только кнопкой.
Вопрос до 2 000 символов, ответ до 2 000 токенов. Текущий вопрос и свежая
сводка разрешённых очередей (названия и полные количества) передаются
DeepSeek. Автоматически не передаются имена, контакты, адреса, тексты
обращений/анкет, ID персон и файлов. Диалог не сохраняется; каждое обращение
самостоятельно. Ответ — обычный текст без исполнения HTML/команд. Ссылки на
источники формирует сервер из доступных виджетов, а не модель.

Серверный DEEPSEEK_API_KEY и AI_ENABLED_PROFILE_IDS (UUID через запятую)
включают доступ явно. Роль сама не включает AI. Пустой список отключает его
для всех. Эмуляция и test-персоны не отправляют платных запросов; права
реального техадминистратора не переносятся на выбранную персону.
Отзыв доступа проверяется каждым запросом. Без доступа блок отсутствует.

20 попыток в календарные сутки Алматы, атомарное резервирование в PostgreSQL
до внешнего вызова. Сбой после резервирования также расходует попытку:
провайдер мог уже начислить оплату. Автоповторов нет. Для действующего
tech_admin суточного предела нет; размер запроса/ответа, общий API rate limit
и таймаут сохраняются. Смена роли/персоны убирает предыдущий ответ.

Внешний API — POST /chat/completions, model=deepseek-flash, thinking disabled,
stream=false; таймаут 30 секунд, фиксированный адрес, без редиректов и SDK.
Ключ/вопрос/ответ не пишутся в журнал. Аудит содержит факт попытки и модель.
Никаких изменений бизнес-объектов ассистент выполнять не может.

## Реализация и проверка

Core: dashboard/assistant*.ts; API: dashboard-handlers и deps; UI:
home-assistant.tsx. Аддитивная закрытая RLS-таблица суточного счётчика.
Сначала тесты доступа/квоты/провайдера, затем API и UI; unit, lint/typecheck,
Deno check/lint/test, build/secret scan, браузер на fixtures.
Интеграционные тесты БД, миграция среды и деплой не запускаются.
После добавления пользователем ключа выполнен платный smoke на искусственной сводке.
Для активации нужны секрет, список пользователей и применение миграции.
