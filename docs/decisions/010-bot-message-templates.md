# ADR-010: Шаблоны сообщений Telegram-ботов

Дата: 18 октября 2026 года. Статус: принято в рамках согласованной спецификации шаблонов.

## Контекст

Тексты регистрации, обращений, заданий и уведомлений требовали изменения кода.
ОСИ нужен редактор на русском и казахском без изменения FSM, полномочий,
адресатов и условий отправки. Основание — [спецификация](../specs/bot-message-templates.md).

## Решение

Дефолты и описание переменных хранятся в `core/src/templates/catalog/`.
Ключи стабильны; каталог объединяет оба бота ADR-009. Подписи кнопок,
описания команд, словари состояний и авторский контент не редактируются здесь.
Условные части уведомлений представлены отдельными вариантами шаблонов;
значения переменных всегда экранируются как текст.

Переопределения хранятся в `message_template` и `message_template_version`.
Последняя версия активна; UPDATE/DELETE версий запрещены триггером.
Откат создаёт новую копию выбранной версии, сброс — новую запись
`use_default=true` с NULL-текстами. Блокировка строки шаблона сериализует
запись, `base_version` обнаруживает устаревший редактор, Idempotency-Key
защищает повтор операции. Версия и аудит записываются одной транзакцией.

`TemplateStore` загружается одним SELECT на входящее обновление, запуск
эмуляции или пакет диспетчеризации. Между вызовами кэша нет. Обновление
шаблона не переписывает уже материализованные уведомления.
Outbox хранит `{template, vars}`; диспетчер выбирает язык получателя и
рендерит текущую версию после проверки доступа. Старые `{text:{ru,kk}}`
и строковые payload продолжают доставляться. Прямые ответы регистрации
без person_id рендерятся при создании `notification`.

Разрешены сбалансированные Telegram HTML-теги `b,i,u,s,code,pre,a,
tg-spoiler,blockquote`. Атрибуты запрещены, кроме постоянного `href`
с http(s):// или tg://. Подстановка в атрибуты не поддерживается.
Оба языка обязательны, каждый не более 4000 символов; неизвестные
переменные при сохранении отклоняются. Существующий HTML/plain-text
каскад и разбиение длинных уведомлений сохранены.

PDP: `settings.templates.read/edit` — chairman, administrator, tech_admin.
Правка privileged, только кабинет; в эмуляции глобальные шаблоны доступны
для чтения. Каждая правка журналируется как `settings.templates.edit`.
Таблицы закрыты от Data API ролями anon/authenticated и RLS.

## Альтернативы

- Все тексты в БД: усложняет первый запуск и синхронизацию с кодом.
- Изменяемая строка «активной версии»: теряет историю и смысл отката.
- Кэш между вызовами: делает момент применения правки непредсказуемым.
- Произвольные выражения/HTML: создают риск выполнения кода и инъекций.

## Проверки

Golden-снимки, валидация HTML, версии/откат/сброс/идемпотентность/аудит,
PDP, материализация обоих форматов, Deno smoke API, тесты редактора.
Миграция и ручная приёмка — только Sydney; Frankfurt не обновляется.
Подробности и ограничения — [приёмка](../bot-message-templates-acceptance.md).
