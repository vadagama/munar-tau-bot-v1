# Инициатор в списке обращений (REQ-01, UI-01)

В таблицу `/requests` добавлен столбец «Инициатор обращения» с ФИО автора (`author_person_id`), включая обращения, созданные сотрудником от имени жителя. При отсутствии имени показано «Не указан». Столбец поддерживает штатную сортировку по алфавиту в обе стороны с пустыми значениями внизу и настройку видимости. Как у прочих столбцов кабинета, сортировка действует на загруженную порцию списка (до 100 записей), перед локальной табличной пагинацией.

Общая строка поиска ищет также по ФИО инициатора. Поиск выполняется сервером до пагинации; фильтры статуса, здания и периода продолжают сочетаться с ним. Ответ списка `GET /v1/requests`, `POST /v1/requests/search` дополнен `author_name`; запрос использует LEFT JOIN к person с совпадением is_test, поэтому отсутствие автора не исключает обращение. Условия доступа, жалобы председателю, чужие черновики и разделение реальных/тестовых данных сохранены.

Проверки: `requests.test.tsx` — отображение, сортировка в обе стороны, пустые имена и передача поисковой строки. `tools/scripts/check-request-initiator.ts` — реальный SQL на синтетических CTE в read-only транзакции: поиск по имени, отрицательный поиск, область зданий, жалобы председателю, черновики, is_test. Скрипт не меняет данные и не выводит личные сведения. Визуальная проверка выполнена в браузере на тестовом стенде.
