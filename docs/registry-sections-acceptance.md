# Объекты эксплуатации — подразделы и фильтры

REG-11 / UI-01, 23.10.2026.

В меню кабинета группа «Объекты эксплуатации» содержит отдельные страницы:

| Подраздел | Адрес | Поиск | Фильтры |
| --- | --- | --- | --- |
| Здания | `/registry/buildings` | Название | Очередь, включая неуказанную |
| Помещения | `/registry/premises` | Здание/адрес, номер, тип, подъезд, этаж, статус | Очередь, здание, тип, статус |
| Привязки помещений | `/registry/connections` | ФИО, телефон, здание/адрес, номер, тип, отношение, основание, статус | Очередь, здание, тип, статус, отношение |
| Очереди | `/registry/phases` | Очередь, здания и адреса в её составе | Очередь, наличие зданий |

Вкладки прежнего реестра убраны. Старый `/registry` перенаправляет на
`/registry/premises`. Текущий подраздел выделяется в открытой группе меню.
Страницы сущностей имеют отдельные ключи, поэтому строки, фильтры и формы
разных подразделов не смешиваются. Прежние ключи настройки колонок сохранены;
у сводки очередей собственный ключ.

Условия поиска и фильтров объединяются и применяются сразу к загруженному
списку. Изменение условия возвращает первую страницу; обновление данных
не сбрасывает выбранные условия. Пустой результат отличается от пустого реестра.

Очереди — существующее поле `building.construction_phase` (1–5), а не новая
сущность БД. Сводка показывает количество зданий и помещений, состав зданий,
а также группу «Не указана». Очередь задаётся в обычной карточке здания.
Подсчёты используют только записи, возвращённые существующим API с проверкой
области и режима эмуляции. Формы записи и серверные проверки не меняются.

В таблице привязок добавлены здание и телефон, уже доступные через существующие
справочники. Создание и редактирование продолжают отправлять прежние поля форм.

Проверки: тесты меню и прямых подразделов; поиск по ключевым полям и русским
подписям; объединение фильтров, сброс, отсутствие очереди; подсчёты только
доступных зданий; первая страница после фильтра; поиск привязки по телефону;
фоновое обновление сводки и ошибка загрузки. Существующие проверки сохранения,
удаления и защиты черновиков реестра продолжают выполняться.

Локально прошли 254 теста кабинета; после уточнения обработки ошибок —
29 тестов реестра. TypeScript, ESLint и production-сборка проверены.
В браузере на локальных фикстурах проверены четыре пункта меню, переходы,
поиск здания, поиск привязки по телефону, фильтр типа помещения и сводка
очередей. В итоговом прогоне консоль без ошибок.
