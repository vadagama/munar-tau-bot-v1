# Панели фильтров кабинета — UI-01

26.10.2026. Основание: запрос пользователя и три снимка экранов.

## Изменение

Общие стили `PageLayout` выравнивают поиск, выбор значений, даты и настройку
колонок по нижнему краю. Поля переносятся целиком; подписи дат остаются сверху.
`FilterDate` задаёт одинаковую с другими контролами высоту из темы AntD.
Мобильный поиск остаётся снаружи свёрнутых фильтров, даты занимают всю ширину.

Проверены маршруты кабинета и места создания фильтров:

| Экраны | Результат |
| --- | --- |
| Обращения, задания | Исправлено общее выравнивание `ListFilters` |
| Общие работы, шаблоны заданий | Две даты с отдельными подписями, как у обращений |
| Жители | Добавлены видимые подписи дат регистрации |
| Отчётность | Общий компонент даты; включительная/исключительная граница сохранена |
| Здания, помещения, связи, очереди, анкеты, сотрудники, приглашения, журнал, шаблоны сообщений, опросы, инициативы | Общие отступы, выравнивание и ширина списков без явно заданной ширины |
| Аварии, регламенты, уведомления, настройки ассистента | Удалены постоянные вводные сообщения над содержимым |
| Главная, документы, публикации, настройки обращений, импорт реестра, эмуляция | Отдельных панелей фильтров нет; формы и контекстные сообщения сохранены |

Удалены все вводные блоки `cabinet-page__intro`, включая пояснения над реестрами,
анкетами, приглашениями, шаблонами, опросами и инициативами. Ошибки, конфликты,
предупреждения в формах, статусы доступа и пояснение выборки из дашборда сохранены.
API, права, состав фильтров и правила отбора данных не менялись.

## Проверки

- TypeScript кабинета, ESLint всего `source/`, production build и проверка сборки
  на секреты прошли. Vite сообщает о размере основного JS-чанка более 500 kB.
- Полный набор модульных тестов кабинета: 66 файлов, 413 тестов прошли.
- Существующие тесты поиска, состояния и дат общих работ/шаблонов, `ListFilters`
  и мобильной иерархии `PageLayout`: 7 тестов прошли.
- В браузере: реальный компонент общих работ и композиция `PageLayout` +
  `ListFilters` + `ConfigurableTable`, локальные пустые данные вместо API.
  Ширины 320, 768, 1024 и 1440 px; перенос полей и раскрытие мобильных фильтров.
  На 1440 px высота всех контролов 32 px, нижние края совпадают.
  На 320 px ширина документа равна 320 px, поля даты занимают доступную ширину.
- Прямая страница предпросмотра без iframe: консоль без ошибок и предупреждений,
  выпадающий фильтр открывается. В оболочке с iframe браузерная проверка показывала
  ошибку MutationObserver; на прямой странице она не воспроизводится.

Проверка не включала авторизацию и живые данные всех страниц стенда.
Интеграционные тесты БД не запускались по правилу проекта.
