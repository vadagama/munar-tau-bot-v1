# Приёмка управления сотрудниками

Дата: 18.10.2026. Основание: ROL-02f, ADR-014; согласованный интерфейс по Обращениям.

## Реализовано

- `/users/staff`: PageLayout, таблица, поиск, фильтры по роли и состоянию, единая CardDrawer и ActionPanel.
- Добавление зарегистрированного пользователя с активным профилем; изменение перечня, смена роли одной записью, снятие всех полномочий и повторное назначение бывшего сотрудника. Только роли и причина, без домов/сроков/спецфлагов.
- Прямые роли и вычисляемое наследование разделены. Председатель → администратор → заместитель → исполнитель; заместитель и выше наследуют duty/doc_reviewer/finance. Служебная область временно всё ОСИ; системные полномочия, объектные условия и запрет собственной приёмки сохранены.
- Сервер разрешает управление только младшими ролями другого пользователя, запрещает системные роли и эмуляцию. Повторно проверяет инициатора под блокировкой, тестовую область, активность профиля, версию и ключ повтора. При отзыве роли прекращаются прикладные сеансы получателя.
- Причина, до/после и инициатор записываются в аудит; обязательное событие staff.roles ставится в outbox в той же транзакции. Шаблон на ru/kk содержит роли, кто изменил, время Алматы и причину. Последняя роль не требуется для получения личного уведомления; test идёт только в simulator. Старые API назначений также уведомляют получателя.
- Карточка показывает количество открытых заданий, сопровождаемых обращений и настроенных расписаний. Прекращение полномочий сохраняет их для явного разбора управляющими, профиль жителя и историю.
- Фоновое чтение сохраняет незавершённую форму при сетевой ошибке. 409 обновляет версию, сохраняет роли и причину, требует повторного подтверждения. Подтверждённый отказ доступа закрывает карточку.
- Поиск кандидатов — POST с `{query}`: имя/телефон не передаются в URL.

## Проверки

- Модульные тесты ядра и кабинета прошли, включая наследование, архивную персону, ограничения управления, повтор, конфликт, отзыв инициатора, аудит/outbox, доставку после последней роли, добавление/редактирование/прекращение полномочий, 409 и сетевую ошибку во время редактирования.
- `npm run lint`, `npm run typecheck`, `npm run build -w admin`: успешно. Сборщик выдаёт предупреждение о размере общего JS-файла более 500 кБ.
- `deno task check`, `deno task lint`, `deno task test`: успешно; 51 Deno-тест.
- `sh tools/scripts/check-build-secrets.sh admin/dist`: секретов не найдено.
- Chromium (установленный Chrome), реальные компоненты с тестовыми ответами API без БД: изменение ролей, полное прекращение полномочий, добавление зарегистрированного пользователя; единственная шторка, формы в границах экрана при 320/768/1024/1440 px, ошибок JavaScript нет.
- `git diff --check`: успешно. Изменения просмотрены по корректности, границам доступа, совместимости, повторным запросам и сохранению предшествующей работы.
