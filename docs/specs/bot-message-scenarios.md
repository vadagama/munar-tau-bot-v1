# Целые сообщения и сценарии бота

Согласовано владельцем в чате: переработать весь каталог и уведомления по предложенной модели.

Единица редактирования — полный ответ на шаг сценария или полное уведомление.
Каталог группируется по разделу, сценарию/команде и варианту. Внутренние слова и
фрагменты скрыты от основного списка. Данные списков, карточек и истории остаются
серверными переменными; администратор меняет окружающий текст. Кнопки показываются
в предпросмотре, подписи меняются отдельно от неизменяемых действий.

Оба языка, серверная HTML-валидация, аудит, идемпотентность, конфликт версий,
откат новой версией и запрет правки в эмуляции сохраняются. Старые ключи и история
не удаляются. Однозначные переопределения учитываются при сборке нового дефолта;
неоднозначный перенос явно обозначается для проверки, без потери старых версий.

Приёмка: полное сообщение /newrequest со списком и кнопками видно в редакторе;
новый текст совпадает с ответом бота; варианты данных и ru/kk проверяемы.
То же правило для регистрации, заданий, аварий, справки, ошибок и уведомлений.
Никаких свободных условий/SQL/выражений в шаблонах. HTML из данных экранируется;
доверенные блоки создаёт только сервер. Без новых зависимостей.

Код: core/src/templates и bot, admin/src/pages/templates, functions/api.
Проверки из source: npm run lint; npm run typecheck; npm test; deno task check;
deno task lint; deno task test; npm run build -w admin; secret-scan.
Полные очищающие интеграции не запускаются. Деплой — после готовности и согласования PR.
