# Главная кабинета — проверка 25.10.2026

Реализовано в отдельной ветке `feature/home-dashboard`, основание —
согласованный интерактивный прототип и разрешение начать реализацию.
Связанные требования: REQ, WRK, REG-01/02a, ROL/PRV, AUTH-06; ADR-021.

## Реализовано

- Разрешённые сервером очереди: новые обращения, требующие действия,
  регистрации, привязки, задания, активные аварии. Полный счётчик и до 20 строк.
- Просрочки внутри очереди действия, без отдельного дублирующего виджета.
- Шестерёнка, скрытие, индивидуальные 3/5/10/20 записей; сохранение по личности
  и test-режиму в браузере. Перестановка Pointer Events и кнопками со стрелками.
- Аналитика созданных/закрытых обращений и видов, день/неделя/месяц/год,
  календарь Алматы. Ссылки сохраняют событие, вид и точный `[from,to)`.
- Сущность открывается в своём разделе как рабочая карточка на странице,
  с прежними действиями и серверной авторизацией. Обычные шторки сохранены.
- Недоступный AI не занимает место; подключение DeepSeek описано ниже.

## Браузер

Проверен реальный React/AntD UI на изолированном локальном Vite-стенде с
демонстрационными ответами API и личности. Стенд не обращается к рабочему
бэкенду и не входит в production bundle.

Подтверждено: настройка 10 и 3 строк, скрытие очередей, сохранение после
перезагрузки, фактическая перестановка мышью, годовой график → закрытые
обращения за октябрь с диапазоном до 1 ноября. Проверены ширины 320, 768,
1024 и 1440; на узком экране подписи периодов помещаются, график прокручивается
внутри карточки. Общая страница не растягивается из-за графика.

## Независимое ревью

Backend: исправлены JSON cast `text::jsonb` и чтение всего архива аварий с
двумя запросами на строку. Повторное ревью не нашло блокеров; 13 тестов
Dashboard/schema-drift прошли. UI: исправлено восстановление карточек
заданий/аварий при Back, добавлена регрессия для задания.

## Незавершённая часть

DeepSeek подключён в коде, но миграция счётчика и серверные секреты ещё
не установлены в облачной среде. Локальный UI использует искусственные данные.

## DeepSeek (ADR-022, 25.10.2026)

Подключён POST `/v1/dashboard/assistant`: серверный ключ, явный список профилей,
20 попыток/сутки Алматы; tech_admin без суточного лимита. Приложенная миграция
`20261025171245_dashboard_assistant_quota.sql` ещё не применена к средам.
RLS включён, PUBLIC/anon/authenticated лишены доступа, клиентских политик нет.
Сбой после резервирования учитывается, автоматических повторов нет.

Проверки: core 157 файлов / 1171 тест; типы; Deno check/lint и 74 теста;
UI ассистента: 4 проверки, включая сохранение 20-го ответа при background
refresh. Мутация исключения tech_admin обнаружена тестами. Независимое ревью
нашло потерю последнего ответа при обновлении лимита; исправлено, добавлен
регрессионный тест. Оркестрационный тест проверяет отсутствие текстов/ID
в контексте модели и квоту до внешнего вызова.

Реальный `deepseek-flash` ответил на искусственную сводку «3+2» корректно.
В браузере выполнен явный запрос по демонстрационным количествам: настоящий
ответ, счётчик 20→19, ссылки на серверные источники. Локальный стенд не читает
рабочую БД; его счётчик временный, production-счётчик PostgreSQL не заменяет.
Ключ из source/.env.local не напечатан, не скопирован в репозиторий/браузер.
Сборка прошла общий secret scan и проверку отсутствия конкретного ключа.

Активация среды: применить миграцию, задать серверные DEEPSEEK_API_KEY и
AI_ENABLED_PROFILE_IDS, развернуть api и кабинет. Добавление ключа только
в локальный env не включает AI на облачном стенде. Откат: очистить список
профилей (прекращает доступ), затем откатить код; счётчик можно оставить.

UI проверен в браузере при 320/768/1024/1440 px; длинные подсказки переносятся. Повторное независимое ревью: обязательных замечаний нет.

Итоговый полный прогон кабинета: 63 файла / 377 тестов успешно. Финальная
сборка кабинета и secret scan прошли. Проверка БД не запускалась по правилу
AGENTS.md; атомарность SQL проверена ревью и unit-контрактом, не интеграционным прогоном.

## Уточнение UX ответов AI (25.10.2026)

- Ответ поддерживает заголовки, выделение, списки, эмодзи и компактные таблицы. Таблица появляется только в аналитическом ответе; постоянного блока «Данные сводки» и переключателя график/таблица нет. Отдельные графики главной сохраняются.
- Ссылки в абзацах и таблицах разрешаются через серверные ref и ведут на списки/страницы карточек. Подпись берётся из серверного источника; произвольный URL модели не становится ссылкой. Контекст дополнен номерами доступных обращений/заданий/аварий без UUID, имён и описаний.
- Таблицы ограничены 8 колонками и 40 строками, некорректная разметка отображается текстом. HTML не исполняется.
- Полный admin-прогон на этапе форматирования: 64 файла, 381 тест. После финального изменения ссылок: 9 UI-тестов и 9 core-тестов; lint/typecheck, production build и secret scan прошли. Независимое ревью проверило allowlist, маршруты и минимизацию контекста.
- Локальный браузер: настоящий ответ DeepSeek на искусственную сводку, таблица со ссылками, переход из ответа на страницу обращения №120. Реальные данные ЖК не передавались.
- Концепт библиотеки исполнителя показан отдельно: поиск по тексту, редактор, пример проверки OCR. Реальное распознавание, хранение и публикация документов пока не реализованы.
