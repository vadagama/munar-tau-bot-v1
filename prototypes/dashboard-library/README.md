# Главная с ассистентом и библиотека документов

Снимок локальных UI-прототипов от 25.10.2026. Сохранён для использования при разработке; не является готовой реализацией бизнес-процессов.

## Запуск

Требуется Node.js 22.12+ и npm.

```sh
cd prototypes/dashboard-library
npm ci
npm run dev
```

Если порт 8770 занят предыдущим просмотром, сначала остановите тот сервер.

- Главная: http://127.0.0.1:8770/dashboard-browser.html
- Библиотека: http://127.0.0.1:8770/library-v3.html?page=docs
- Документ: http://127.0.0.1:8770/library-v3.html?doc=water
- Состояние исчерпанного лимита: http://127.0.0.1:8770/assistant-limit.html

`npm run build` проверяет сборку обеих страниц. Для демонстрации ассистента используйте dev-сервер: его локальный API не включается в статическую сборку.

## Ассистент

Без ключа возвращает фиксированный демонстрационный ответ. Для реальных ответов создайте здесь `.env.local` со строкой `DEEPSEEK_API_KEY=...` и перезапустите сервер. Ключ читается сервером и не включается в клиентскую сборку. Реальные вызовы расходуют квоту провайдера. Сохранённые материалы не содержат ключа.

Локальный сервер использует учебную сводку, лимит 20 запросов на процесс и не воспроизводит production-авторизацию, персональные тарифы или исключение для технического администратора. Связанные разделы и переходы реализованы частично.

## Библиотека

- «О документе»: метаданные и редактирование на месте.
- Назначение определяет включение в техническую библиотеку; «Все документы» содержит обе категории.
- Редактор BlockNote: форматирование, таблицы и изображения внутри текста, меню `/`, кнопка «Исходник», экспорт Markdown.
- История версий и создание черновика из версии.
- Демонстрационный выбор роли; для исполнителя содержимое доступно только для чтения.

Метаданные, черновики, загруженные изображения и версии живут в памяти страницы до перезагрузки. Изменения, сделанные ранее в браузере, не входят в этот архив. OCR, серверное хранение, согласование, аудит и PDP здесь не реализованы. Изменение назначения/объекта лишь помечает документ черновиком; сохранение опубликованного снимка до согласования — задача основной реализации. Объект сейчас выбирается один. Ответственные представлены демонстрационными значениями.

## Структура и применение

- `dashboard-browser.tsx`, `api.ts`, `identity.ts` — стенд главной и учебные данные.
- `assistant-server.mjs` — серверная демонстрация AI.
- `library-v3.tsx` — каталог и навигация библиотеки.
- `editor-runtime/document-editor.tsx` и `.css` — редактор, метаданные, версии.
- `snapshot/` — необходимые исходники кабинета и общих модулей на момент сохранения. Благодаря снимку прототип не зависит от временного worktree и его последующих изменений.
- `screenshots/` — контрольные виды интерфейса.

Используйте прототип как UX-референс и источник компонентов. Не переносите заглушки API, роли и ограничения демонстрационного сервера в production. Зависимости изолированы от основного проекта; package-lock.json фиксирует версии.
