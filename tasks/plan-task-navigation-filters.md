# Раздел «Задания» и фильтры общих работ/шаблонов

Запрос пользователя 22.10.2026, ветка `feature/admin-ui-changes`, PR #71.
Требования: UI-01, WRK-11, JOB. Домен «Общая работа» сохраняется; задания по
расписанию остаются отдельными заданиями, создаваемыми из шаблонов.

- [x] Родитель «Задания»: «Все задания» (`/tasks`), «Общие работы», «Шаблоны заданий». Прямая ссылка раскрывает группу и выделяет пункт. Первое доступно всем сотрудникам, управление — только chairman/administrator/deputy.
- [x] Заголовок `/tasks` — «Все задания». Убраны «К заданиям» из общих работ и шаблонов; переходы к созданному заданию/форме сохраняются.
- [x] Общие работы: мгновенный поиск по номеру/названию/описанию, состояние, диапазон дат создания.
- [x] Сохранённые шаблоны: поиск по названию/инструкции, активность, диапазон дат создания. Границы включают выбранные дни Алматы, обратный период показывает предупреждение. Сортировка и настройка колонок остаются общими.

Приёмка: 203 теста кабинета, admin typecheck, общий lint, admin build и
secret-scan. В браузере проверены раскрытая группа меню, фильтры обеих страниц,
мгновенный поиск шаблонов и отсутствие «К заданиям». Интеграционные тесты не
запускаются по AGENTS.md. Внешний деплой не выполняется.
