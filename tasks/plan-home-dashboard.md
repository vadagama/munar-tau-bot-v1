# Главная кабинета: согласованный рабочий обзор

Согласовано в чате 25.10.2026: интерактивный прототип и «Можно начинать делать».
Требования: REQ/WRK, REG-01/02a, ROL/PRV, AUTH-06.

## Контракт
Сервер возвращает только доступные виджеты и записи; счётчики/аналитика
вычисляются после ограничения доступа, не из первой страницы. Test изолирован.
Ссылки ведут в существующие разделы к конкретной сущности. График переносит
период, вид и дату события в фильтры списка; календарь — Алматы.
Регистрации без помещения и заявки на привязку разделены. Просрочки входят
в требующие действия, отдельной плашки нет. Состав, порядок, 3/5/10/20 строк
персональные. Перестановка мышью, касанием и клавиатурой.
AI над виджетами, отсутствие доступа скрывает блок. Провайдер не имитируется.
Смена персоны убирает прежние данные сразу, включая поздние ответы запросов.

## План и проверка
- [x] Данные главной и аналитика: серверный доступ, полный подсчёт, DTO.
  Проверка: unit периода/политик, Deno check/lint.
- [x] UI очередей и персональных настроек, реальные ссылки.
  Проверка: Vitest настроек/главной, typecheck/build.
- [x] Фильтры списка для графиков, переходы регистраций/помещений.
  Проверка: unit URL, браузер.
- [ ] AI-контракт по ответу пользователя; документация, ревью и PR.
  Проверка: недоступность без подключения, lint, unit, secret scan.

## Границы
React/AntD, существующий API/PDP. Не менять права ради сходства с макетом:
исполнитель не получает исходное обращение по одному назначению задания.
Интеграционные тесты с БД запрещены без отдельного запроса; мерж и деплой
не выполняются. Подключение AI — отдельный выбор провайдера и бюджета.

Проверки и ревью: `docs/home-dashboard-acceptance.md`. AI остаётся отключён
до выбора провайдера и бюджета; в этом срезе нет имитации рабочего AI.
