# Очередь строительства здания (REG-11)

Согласованный объём от 19.10.2026: добавить зданию свойство и фильтр. Каждое здание относится максимум к одной очереди 1–5; до заполнения очередь не указана. Регистрация, карта (в текущем кабинете отсутствует), распределение домов по очередям и Excel-шаблон в этот объём не входят.

## Приёмка

- `building.construction_phase`: nullable smallint, CHECK 1–5; существующие здания остаются с NULL.
- Создание/изменение через общий сервис реестра: принимаются целые 1–5 и null; пропуск при PATCH сохраняет прежнее значение. Изменения и аудит атомарны; действующие права председателя и запрет эмуляции сохраняются.
- Форма здания: необязательный Select «Очередь строительства», очистка сохраняет NULL; значение видно в таблице.
- Фильтр во вкладке «Здания»: все / очереди 1–5 / не указана. С другими вкладками не применяется; фоновое чтение сохраняет фильтр и открытую форму.
- Никаких новых зависимостей, изменений прав, импортов и сценария регистрации.

## Реализация и проверки

1. Миграция и серверная валидация в `source/db/migrations`, `source/core/src/domains/registry`.
2. Форма и фильтр в `source/admin/src/pages/registry.tsx` по существующему PageLayout/Ant Design.
3. Модульные тесты в соседних `*.test.ts(x)`; интеграционные тесты сохранить, не запускать без отдельного запроса.
4. Из `source/`: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build -w admin`, `deno task check`, `deno task lint`, `deno task test`, `sh tools/scripts/check-build-secrets.sh admin/dist`.
5. Обновить REG-11, модель Building в HLD и AGENTS.md. PR оставить на согласование.
