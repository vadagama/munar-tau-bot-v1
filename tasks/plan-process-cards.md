# Единые карточки процессов (UI-01, REQ, WRK, REG, EMG, NTF)

Согласованное направление: карточка объясняет текущее состояние, ожидаемого участника, срок и следующий шаг; затем показывает содержание и материалы, обсуждение и свёрнутую историю. Существующие переходы, PDP, версии, формы и аудит сохраняются.

## Область
Обращения, задания, общие работы, аварии, публикации; решения/управление анкетами, результат контакта при недоставке, регулярные запуски и восстановление Telegram. Карточка сотрудника получает пояснение открытых обязанностей; справочники и редакторы настроек не получают искусственный жизненный цикл.

## Срезы и приёмка
- [x] Общие ProcessOverview / ProcessActions / ProcessHistory: одно главное действие, частые альтернативы, раскрываемые прочие; неизвестные состояния без придуманного перехода; история по умолчанию свёрнута; разворачивание Drawer.
- [x] Обращения: процесс перед информацией, роль автора/управляющего, отдельное ожидание, реальные незавершённые обязательные задания; существующие формы доступны.
- [x] Задания: инструкции/отчёты/история разделены; проверка отчёта перед решением; собственная приёмка запрещена как раньше; последняя ошибка доставки компактна.
- [x] Общие работы / аварии / публикации: те же блоки и иерархия; аварии используют серверный список действий, ожидание согласования без фиктивной кнопки.
- [x] Остальные процессные формы: цель и последствия до ввода, существующее сохранение и причины.
- [x] Проверки: unit сценарии состояния/роли/неизвестного состояния; регрессия форм; admin typecheck, lint, все admin tests, build/secret scan; браузер и скриншоты. Интеграционные БД-тесты и внешняя выкладка не входят.

## Риски
Подсказка не заменяет серверные проверки. Ожидание не означает право управлять другим объектом. Нет общего линейного степпера: процессы разветвляются и возвращаются. Фоновое обновление не сбрасывает формы. Даты отображаются в Алматы. Новые компоненты используют существующий AntD 5 и токены.

## Итог проверки
222 теста кабинета прошли; дополнительно 27 тестов задания проверены после уточнения проверки предыдущих версий отчётов. Typecheck кабинета, общий lint, build и secret scan прошли. В браузере проверены обращение/форма начала работы без записи, авария, карточка задания и разворачивание. Ошибок приложения в консоли нет; остались прежние предупреждения React Router о будущих флагах v7. Сборка содержит прежнее предупреждение о размере общего JS chunk.

При сверке состояния публикаций исправлен доступный следующий шаг согласованного финансового отчёта: при `approved_by` предлагается публикация, а не повторное согласование. Серверные releaseChecks сохранены. Это покрыто тестами состояния и карточки.
