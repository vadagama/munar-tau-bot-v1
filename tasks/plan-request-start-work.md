# Начало работы из обращения (REQ-05, WRK, TIM, ROL-02d)

Согласовано 18.10.2026: ответственный в форме — исполнитель задания.

- Форма «Начать работу»: исполнитель из разрешённой области, редактируемое описание работы, срок выполнения. Название задания формируется по номеру обращения; место берётся с сервера. Для жалоб/вопросов описание по умолчанию предлагает подготовить ответ, не копирует переписку.
- Одна серверная транзакция создаёт обязательное задание с request_id и переводит обращение в работу. Назначенное задание ожидает явного принятия исполнителем; уведомления идут через существующий outbox в бот сотрудников.
- Idempotency-Key и версия обращения защищают от повторов, устаревшей формы и параллельных нажатий. Ошибка назначения/перехода откатывает всю операцию.
- В карточке обращения сотруднику доступны связанные задания с номером, исполнителем, состоянием и сроком. В карточке задания сотруднику с доступом к обращению — обратная ссылка. Переписка и внутренние материалы не копируются исполнителю.
- При уже существующих заданиях они остаются видны; новый явный запуск создаёт отдельное задание. Повтор одной операции не создаёт дубль. Находясь в работе, обращение не предлагает повторный «Начать работу».
- Обязательный результат созданного задания включается в существующую проверку готовности ответа, в том числе для вопроса/жалобы.

Проверки: модульные тесты операции и UI, typecheck/lint, Deno, сборка и secret-scan, визуальная проверка форм и ссылок. Интеграционные сценарии сохраняются, но не запускаются без отдельного запроса.
