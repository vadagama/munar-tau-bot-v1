# Общая структура экранов кабинета

Основание: указание пользователя от 18.10.2026, эталон — экран обращений.
Сохраняются ADR-002, серверный PDP и ограничения AUTH/REQ/WRK/REG/TIM.

- [x] Общий каркас: заголовок с переключателем вида, строка действий, фильтры, рабочая область.
- [x] Перенос страниц списков: обращения, задания, регистрации, помещения/пользователи, аварии, публикации, приглашения, журнал.
- [x] Перенос настроек, шаблонов, общих работ, эмуляции, импорта и главной; без пустых действий/фильтров.
- [ ] Проверки: тесты кабинета, lint, typecheck, build, secret-scan; визуальная проверка основных вариантов.

Критерии: один общий заголовок на страницу; действия выше фильтров; рабочая область ниже них;
перенос элементов на узкой ширине; формы, права, автообновление и прокрутка досок сохраняются.
Вход через Telegram — отдельный экран авторизации, без служебных действий и фильтров.

Проверки завершены: 100 тестов кабинета, typecheck, lint, build и secret-scan прошли.
В браузере проверены обращения (доска и открытая карточка) и задания (таблица).
Полный визуальный обход остальных экранов и контрольные ширины 320/768/1024/1440 не завершены: пользователь подтвердил текущий вид и остановил дальнейший обход.

## Разделение публикации

Общий каркас и автообновление публикуются первым PR; карточка обращений и начало работы — следующим зависимым PR. Проверки промежуточного среза указаны в описании PR.
