# Перестройка навигации кабинета

Основание: запрос пользователя от 18.10.2026. Требования: REG (реестр и регистрации), ROL-01–04 (служебные назначения), NTF-03 (недоставки), TIM-02 (регламенты). Новых полномочий и миграций данных нет.

## Согласованная структура

Порядок: Главная → Обращения → Задания → Аварии → Публикации → Пользователи → Помещения → Уведомления → Журнал действий → Настройки.

- Пользователи: Жители, Сотрудники, Регистрации, Приглашения.
- Помещения: здания/паркинги, помещения и их привязки к пользователям.
- Уведомления: Ошибки доставки, Мои настройки. Ошибки доступны прежним управляющим ролям.
- Настройки: Импорт и экспорт, Настройки обращений, Регламенты, Шаблоны сообщений, Эмуляция ролей (пилот). Прежняя кнопка «Категории и файлы» из обращений убрана.

Человек с действующим служебным назначением показывается в сотрудниках, включая совмещение с проживанием; без такого назначения — в жителях. Учитываются статус и сроки назначения. Сотрудники без помещений видны по области служебного назначения; люди, уже доступные через помещения в области, сохраняют видимость. Председатель видит весь ОСИ. Тестовые и обычные персоны разделены. Назначение и отзыв ролей в этот запрос не входят; редактирование данных и восстановление Telegram используют прежние серверные проверки.

## Реализация и приёмка

1. Вложенное меню с прежними условиями видимости. Прямая ссылка раскрывает нужную группу и выделяет пункт; импорт раскрывает «Настройки» и выделяет «Импорт и экспорт». На узком экране меню открывается поверх содержимого и закрывается после перехода.
2. Отдельные страницы жителей/сотрудников на общем редакторе реестра; GET `/v1/registry/staff` защищён `registry.read`, областью домов и `is_test`.
3. Отдельные страницы предпочтений и недоставок. Они загружают только данные своего подраздела. Прежний `/notifications` перенаправляет на личные настройки.
4. Настройки обращений — самостоятельная страница; в эмуляции и без управляющей роли недоступна.
5. Модульные проверки меню, разделения пользователей, редактора категорий, уведомлений и передачи области в каталог сотрудников. Полные Node/Deno-проверки, lint, typecheck, build и secret-scan; браузерная проверка на локальных фикстурах при 320/768/1024/1440 px.

Интеграционные тесты с БД не запускать без отдельного явного запроса. Браузерные фикстуры не подтверждают SQL на реальной БД. Для публикации необходим совместный выпуск `api` и кабинета; миграций нет. PR остаётся на согласование.
