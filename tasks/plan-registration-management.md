# Управление анкетой — план реализации

Спецификация: `tasks/spec-registration-management.md`, согласована 21.10.2026. Именование плана соответствует конвенции AGENTS.md; прежние tasks/plan.md и tasks/todo.md относятся к VS-0 и не изменяются.

- [x] 1. Исправление подтверждённой анкеты: снимок прежних данных, версия, подача кандидата в той же записи, одобрение/отказ без утраты прежнего доступа. Файлы: миграция, service.ts, registration.ts, тесты бота/домена. Проверка: focused Vitest + typecheck. Зависимостей нет.
- [x] 2. Единая основная анкета: частичный уникальный индекс, блокировка подачи, сохранение исторических дубликатов с отметкой superseded_by, повторное использование основной записи. Проверка: тесты повторов; SQL миграции; /add не ограничен. Зависит от 1.
- [x] 3. Управление анкетой: общий домен management.ts, PDP, API, тесты. Удаление атомарно закрывает сеансы/связи/роли и не удаляет историю. Проверка: права, версии, идемпотентность и изоляция. Зависит от 1–2.
- [x] Контроль: focused тесты ядра и Deno, ревью ограничений полномочий.
- [x] 4. Кабинет: исправление/удаление с причиной и подтверждением, предложенные/действующие данные; серверные возможности, стабильные формы при обновлении. Проверка: тесты UI и браузер. Зависит от 3.
- [x] 5. Бот: удаление, полезные лаконичные ответы ru/kk, кнопки без дублирования команд в тексте. Проверка: сценарии бота и каталога. Зависит от 3.
- [x] 6. Документация: ADR-016, требования REG/PRV, AGENTS, приёмка. Общие проверки, независимое ревью, PR в main без слияния. Зависит от 1–5.

Интеграционные тесты против облачной БД не запускаются без явного запроса, согласно AGENTS.md. Изменения схемы не применяются к демонстрационному стенду в рамках тестирования. Публикация — миграция до функций/кабинета.

Проверено: 677 тестов ядра, 170 кабинета, 57 Deno; TypeScript, ESLint, Deno check/lint и сборка. Миграция дважды проверена на локальном PostgreSQL (PGlite), включая выбор основной записи, сохранение дублей и unique/version. Браузер: локальная форма исправления, статус проверки/сохранённого доступа, предупреждение удаления и обязательная причина; используются вымышленные данные без облачного API. Ревью: замечания про обход версии, исторический спор, повторную подачу, актуальную аудиторию уведомлений и конкурентное добавление помещений устранены.
