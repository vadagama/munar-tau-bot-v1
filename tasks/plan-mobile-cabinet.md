# Мобильный кабинет — UI-01

Согласовано в чате 25.10.2026: список без доски, компактные фильтры,
шапка и полноэкранная карточка. Команда «Внеси требуемые изменения» разрешает реализацию.

## Контракт
- До 768 px: мобильный список; сохранённая настольная доска не включается и не стирается.
- Шапка: меню, название, профиль. Навигация в закрытой по умолчанию шторке с полными подписями.
- Обращения/задания: поиск рядом с фильтрами, панель снизу с черновиком и применением,
  сброс, активные метки. Настольные фильтры продолжают применяться сразу.
- Общий ConfigurableTable: на мобильном записи расположены вертикально.
  Обращения/задания имеют компактное предметное представление.
- CardDrawer занимает всю ширину, сохраняет защиту несохранённых данных и доступные действия.
- Данные, PDP, API и бизнес-переходы сохраняются. Новых зависимостей нет.

## Порядок и проверки
1. Общий breakpoint, меню/шапка, мобильный режим списков и карточки.
2. Панель фильтров обращений/заданий и метки выбранных значений.
3. Vitest поведения, typecheck, lint, build; браузер 393×852 и настольный размер.
4. Обновить правила и приложить результаты в PR, без мержа.

Код — source/admin/src; тесты рядом (*.test.tsx), существующий стиль React/AntD.
Команды из source: npm run test -w @munar/admin; npm run typecheck -w @munar/admin;
npm run lint; npm run build -w @munar/admin.
